# Java Servlet – يونيو 2002

🔗 دورة تدريبية عبر الإنترنت: https://stahe.github.io/ar-servlets-java-juin-2002/

## مقدمة

هذا المستند هو **مذكرة دورة تدريبية** مخصصة للبرمجة على الويب بلغة Java (Servlet، بيئة J2EE).

وهو ليس دورة كاملة. فهناك بعض الموضوعات التي تتطلب إرشاد مدرب، كما أن هناك عدة مواضيع مهمة لم يتم تناولها.

الهدف الرئيسي هو تزويد الطلاب بالأدوات اللازمة للعمل بشكل مستقل على أساسيات تطوير الويب بلغة Java.

## المراجع

أهم المراجع هي:

1. *J2EE Programming* – Wrox (موزع من قبل Eyrolles)
2. *Java Server Pages* (Fields, Kolb) – Eyrolles
3. *Java Servlet Programming* (Hunter) – O'Reilly

يعتمد جزء كبير من المحتوى على الكتاب الأول، الذي يعتبر أكثر شمولاً بكثير من هذا المورد.

## مواضيع إضافية لم يتم تناولها

يمكن إثراء هذا المستند بإضافة المواضيع التالية:

- برمجة XML
- علامات JSP
